# Правила проекта avi-town

Пет-проект на GitHub: `github.com/Assinross/avi-town`. Игра - `packages/client`,
симуляция - `packages/sim`, константы баланса - `packages/data`.

## Git

- Работаем в основной ветке `main`, отдельные ветки не создаём.
- Коммит и пуш - после каждого законченного этапа (правило Avi, 2026-11-13),
  отдельного разрешения не спрашиваем. Пуш в `main` сразу выкладывает игру на
  GitHub Pages.
- Сообщение коммита - по-русски, одной строкой, как в истории: "Граф улиц: ...",
  "Дороги: ...", "Полосы и манёвры: ...".
- `specs/`, `docs/`, прототипы, `.agents/`, `.serena/`, `.idea/` не коммитим.
- Чужие правки в тех же файлах (параллельная сессия, правки Avi) не берём:
  коммитим только свои файлы и свои куски.

## Проверки

- `npm run build` может падать с ошибкой snap-confine; работает
  `npx vite build packages/client`.
- Дев-сервер: `npx vite packages/client --port 5174 --strictPort`.
- Тесты и typecheck не пишем и не запускаем без отдельной просьбы (решение Avi).
- Снимки: `?slice`, `?bench`, `?showcase`; ночь - `?hour=22`; сравнение - `?fx=-<флаг>`.

## Язык

- Ответы и документы - по-русски, просто. Обычный дефис, прямые кавычки.
