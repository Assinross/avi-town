# Avi Town 2.0

Браузерная стратегия о строительстве и обороне колонии на постапокалиптической пустоши. В режиме вторжения город обеспечивает энергию, промышленность, исследования и защиту от НЛО; отдельно доступен мирный градостроительный режим.

**Играть:** https://assinross.github.io/avi-town/

## Реализовано в исходном коде

- **Город:** процедурная карта по сиду, дороги, зонирование (жильё, торговля, промышленность, фермы), бюджет и налоги, еда, занятость, загрязнение, вода, электричество, услуги, строительство и ремонт.
- **Кампания:** три фазы (первый контакт, вторжение, контрнаступление), шкала угрозы, начальный выбор, пять типов операций пришельцев, условия победы и поражения.
- **Оборона:** радары, ПВО, исследовательские технологии, бункер, броневик, отряд с ролями, снаряжением, тактикой, приказами сосредоточить огонь и отступить. Бои идут автоматически на общей карте.
- **Военная экономика:** три доктрины (ПВО, наземные отряды, наука), производство комплектов в мастерской, расход ресурсов и боекомплектов.
- **Служба восстановления:** после разрушения здания остаются завалы; управление с электропитанием и дорожным доступом назначается на расчистку, затем исходная зона освобождается. **Анимированного выезда коммунальной машины и оцепления пока нет.**
- **Интерфейс и сохранения:** командный центр, журнал до 80 записей, звуковые сигналы по желанию игрока, автосохранение, миграции ряда старых форматов и отдельные сохранения мирного режима.
- **Транспорт:** дорожный граф, автомобильный трафик, автобусные депо, остановки и настройка маршрутов. Полнота влияния автобусов на городскую экономику требует отдельной проверки.
- **Графика:** Three.js, процедурная геометрия, спрайты и импортированные GLTF/GLB-модели (KayKit, Kenney, Quaternius и другие наборы); день/ночь, тени, дым повреждённых зданий, эффекты налётов.

**Ограничения:** полноценный пошаговый бой XCOM не используется (старый код оставлен в `packages/sim/src/battle`). Совместимость *всех* исторических сохранений не гарантируется: например, формат дорог со старым значением `road === 2` отклоняется загрузчиком. Сетевая игра по Wi-Fi не подтверждена текущей реализацией и не заявляется как готовая функция.

Перечень означает наличие реализации **в коде**, а не проверенную проходимость, баланс или производительность. Точные статусы и задачи находятся в [дорожной карте](AVI_TOWN_2_0_ROADMAP.md).

## Запуск

Нужны Node.js и npm. Из корня репозитория:

```bash
npm install
npm run dev
```

Для локальной разработки по `AGENTS.md`:

```bash
npx vite packages/client --port 5174 --strictPort
```

Сборка: `npm run build`; при проблеме с `snap-confine` использовать `npx vite build packages/client`. Результат находится в `packages/client/dist`. Тесты и typecheck без отдельного разрешения в рабочем процессе не запускаются.

Полезные параметры в dev-режиме: `?seed=123` (новая карта по сиду), `?slice`, `?bench`, `?showcase`, `?hour=22` и `?props` (галерея процедурных предметов). Режимы и сохранения выбираются через интерфейс.

## Структура проекта

| Каталог | Назначение |
|---|---|
| `packages/sim` | Детерминированная симуляция, команды, кампания, бои, экономика, сохранения |
| `packages/data` | Данные баланса, здания, противники, технологии, локализация |
| `packages/client` | Vite, TypeScript, Preact, Three.js, интерфейс и рендер |
| `packages/client/public/models` | Используемые наборы моделей, их README и условия лицензий |
| `tools` | Вспомогательные инструменты, включая извлечение текстов XCOM |
