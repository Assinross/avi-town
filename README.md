# Avi Town

Браузерный постапокалиптический градостроитель с обороной в стиле XCOM.
Строим город на пустоши, добываем еду и материалы, исследуем технологии,
сбиваем НЛО и проводим пошаговый бой прямо на улицах города. Игра на одного
или вдвоём по Wi-Fi.

**Играть:** https://assinross.github.io/avi-town/

## Сейчас готово

- Изометрическая карта пустоши по сиду: руины старого города, вода, заражённые
  участки, камни, деревья (`?seed=123` в адресе - новая карта).
- Процедурная мультяшная графика с контурами, без текстур и моделей.
- Город: дороги, зоны (жильё, торговля, промзона, фермы) протягиванием
  прямоугольника, рост зданий по 3 уровням, спрос, налоги и содержание.
- Выживание: еда с ферм (плодородная земля даёт больше), голод снижает
  довольство и население; промзона загрязняет жильё рядом.
- Ток и вода: генератор и насосная (у реки - больше воды), сеть идёт по дорогам;
  слои "кто получает ток/воду".
- XCOM: лаборатория (исследования по дереву XCOM с оригинальными названиями
  и описаниями), мастерская (ремонт, металл), радар (предупреждает о налёте).
- Шахты и промзона на камнях/заражённой земле дают металл.
- Налёты НЛО (малый разведчик ... корабль террора): тарелка кружит над городом и
  разрушает здания; ПВО "Лавина", "Феникс", лазерная, плазменная, термоядерная -
  открываются исследованиями. Сбитое НЛО падает в городе.
- Тактический бой (первая версия): отряд вызывается к месту крушения как пожарные,
  город встаёт на паузу, камера приближается к улице. Поле боя - реальные здания,
  руины, деревья и брошенные машины района. До контакта - движение в реальном
  времени, после - пошагово по правилам XCOM: 2 очка действия, рывок, укрытия,
  шанс попадания, туман войны, рывок пришельцев в укрытия. Трофеи - в исследования.
- Время: пауза и 3 скорости; отмена Ctrl+Z; автосохранение в браузере.
- Камера: колесо - приближение до уровня улицы, Q/E - поворот, ПКМ/пробел+ЛКМ/WASD -
  сдвиг.

## Запуск локально

```bash
npm install
npm run dev
```

Сборка: `npm run build` (результат в `packages/client/dist`).

## Устройство

- `packages/sim` - ядро игры: мир, команды, детерминированный ГСЧ; без отрисовки.
- `packages/data` - данные и баланс (здания, исследования, НЛО), тексты;
  `locale/ru.xcom.json` собирается `npm run extract:xcom` из локальной копии XCOM.
- `packages/client` - браузерный клиент: Vite, Three.js, Preact.
