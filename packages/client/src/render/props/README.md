# Предметы `render/props/`

Мелочи улиц, дворов и промзоны (скамейки, контейнеры, качели, ящики...) и машины. Каждый предмет - отдельный файл, собирается кодом из простых деталей, без текстур и без загрузки моделей.

Образцы: `bench.ts` (скамейка), `dumpster.ts` (мусорный контейнер), `vehicles/van.ts` (фургон). Новый предмет пишется по их образцу.

## Правила

1. **Метры.** Предмет описывается в метрах, как в жизни: скамейка 1.7 м, контейнер 1.3 м. В мир переводит `kit.ts` (клетка = 1 единица ~ 10 м, `M = 0.1`). Житель в игре - 1.6 м.
2. **Машины** - тоже в настоящих метрах, но с `scale: VEHICLE_SCALE` (сейчас 0.5: машины на улицах пока мельче жизни, решится на этапе 3). Файлы машин - в `vehicles/`.
3. **Точка опоры** - `(0, 0, 0)`: на земле, в центре предмета. Ничего не ниже `y = 0`; колёса касаются земли.
4. **Фасад к +z**: лицо предмета (сиденье скамейки, капот машины, дверца киоска) смотрит в +z. Повернёт тот, кто ставит.
5. **Цвета - только из `palette.ts`**: `PALETTE.<имя>` и `pick(список, variant)`. Нужен новый цвет - добавить именованный ключ в блок "Предметы render/props/" в конце палитры. Тень и оттенок можно получить из цвета палитры (`new THREE.Color(c).multiplyScalar(0.8)`), как крышка в `dumpster.ts`.
6. **Детали только через `PropBuilder`**: `box`, `boxAt` (с наклоном/поворотом через матрицу), `wedge` (клин: стекло, скат), `cylinder` (колёса, трубы, столбы). Все детали замкнутые, с дном - иначе тень будет с дырами.
7. **Варианты** - число `variants` и ветки по номеру `v` (цвет, форма, открыто/закрыто). Без `Math.random`: один и тот же номер всегда даёт один и тот же предмет.
8. **Бюджет**: мелочь двора - до ~400 треугольников, машина - до ~1500. Цилиндры - 8-12 граней.
9. **Тени включены** сами: склейка в участок и `propMesh` отбрасывают и принимают тень. Ничего для этого делать не нужно.
10. **Один стиль**: спокойные цвета палитры, детали объёмом (рама, обод, ручка, шов), без мелкого шума. Город "восстанавливают после катастрофы": можно ржавчину, заплатки, разномастные доски.

## Как добавить предмет

1. Создать файл `<имя>.ts` (машина - `vehicles/<имя>.ts`) по образцу `bench.ts`: экспорт `const ИМЯ: PropDef = { id, name, variants, build(p, v) { ... } }`.
2. Добавить его одной строкой в список `PROPS` (или `VEHICLES`) в `index.ts`.
3. Открыть страницу `?props` (dev-сервер, `http://localhost:5174/?props`): каждый предмет - ряд из всех вариантов, рядом подпись. Машины стоят на дороге рядом с легковой KayKit для сравнения масштаба.
4. Снимок страницы - в `specs/010-cityrt-world/shots/props-<имя>.png`. Приёмка - Avi по снимку.

Другие файлы (`kit.ts`, чужие предметы, `palette.ts` кроме своего ключа) не трогать.

## Как предметы попадают в игру

- **Склейка в участок** (дворы, улицы): `placeProp(g, BENCH, variant, x, y0, z, rot)` - предмет вклеивается в общий меш участка (`GeoBuilder`), с тенями и контуром.
- **Пачка** (машины, массовые мелочи): `propMesh(VAN, variant, count, material)` - `InstancedMesh`, матрицы экземпляров ставит владелец (как машины в `traffic.ts`).
- `rot` - поворот вокруг вертикали, как у `GeoBuilder.box`: `rot = 0` - фасад к +z.
