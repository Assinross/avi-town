# Здания торговли: Kenney City Kit (Commercial) 2.1

Источник: https://kenney.nl/assets/city-kit-commercial
Лицензия: CC0 1.0 Universal (Public Domain) - https://creativecommons.org/publicdomain/zero/1.0/
Автор: Kenney (https://www.kenney.nl). Атрибуция не требуется, но указана с благодарностью.

Формат: GLB, цвета из общей текстуры-палитры `Textures/colormap.png`.
Взяты дома `building-a..n`, небоскрёбы `building-skyscraper-a/b/c/e` и зонтики кафе `detail-parasol-a/b`.

Файлы копируются как есть, без правок. Масштаб, центровка и перекраска стен под палитру игры
делаются в коде (`packages/client/src/render/models.ts`).
