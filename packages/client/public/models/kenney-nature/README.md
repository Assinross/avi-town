# Посевы ферм: Kenney Nature Kit

Источник: https://kenney.nl/assets/nature-kit
Лицензия: CC0 1.0 Universal (Public Domain) - https://creativecommons.org/publicdomain/zero/1.0/
Автор: Kenney (https://www.kenney.nl). Атрибуция не требуется, но указана с благодарностью.

Формат: GLB, без текстур - цвета в материалах.
Взяты посевы по стадиям (`crops_cornStage*`, `crops_wheatStage*`, `crops_leafsStage*`), овощи
(`crop_pumpkin`, `crop_melon`, `crop_carrot`, `crop_turnip`), грядки (`crops_dirtRow`, `crops_dirtDoubleRow`)
и поленница `log_stack`.

Файлы копируются как есть, без правок. Масштаб и центровка делаются в коде
(`packages/client/src/render/models.ts`).
